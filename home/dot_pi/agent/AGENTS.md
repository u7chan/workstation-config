# 出力の作法

## チャット出力でのリンク

- チャット（pi の応答）で Issue / PR 番号やコミット SHA に触れるときは、[#2084](https://github.com/u7chan/monorepo/pull/2084) のようなマークダウンリンクで書く。リンクテキストは番号だけにし、裸の URL は書かない。
- 参照として示す番号はバッククォートで囲まない。記法そのものを説明するときだけ囲む。
- リンクの owner / repo はカレントディレクトリの origin から取る。
- GitHub 上の本文・コメント・コミットメッセージは GitHub 側が `#NNNN` を自動リンクするため、素の `#NNNN` / `(#NNNN)` のままでよい。
